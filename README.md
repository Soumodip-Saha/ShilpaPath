## 🎯 1. The Problem Statement & Contest Focus

Commercial travel aggregators (MakeMyTrip, TripAdvisor) focus exclusively on commercial hotels and urban mass tourism. In contrast, Eastern India’s living craft hubs—supported by West Bengal’s **Rural Craft and Cultural Hubs (RCCH)** initiative, Bihar's ancient art corridors, and Jharkhand’s tribal guilds—suffer from acute digital invisibility:

1. **Middleman Exploitation:** Rural artisans receive only a fraction of market value through intermediary emporiums.
2. **Missing In-Situ Context:** Travelers arriving in places like Panchmura (Bishnupur) or Charida (Purulia) find no plaques, guided trails, or historical narratives.
3. **App Store Fatigue:** Forcing tourists to download heavy native apps for a single village trail results in immediate drop-off.
4. **Spotty Rural Connectivity:** Cellular connections fluctuate drastically along rural corridors in Bankura, Medinipur, Madhubani, and Hazaribagh.

### The Sanskriti Solution
**Sanskriti** is a lightweight, mobile-first web platform combining:
- **Scan-to-Listen Audio Trails** in **33 languages** (the 22 Eighth Schedule Indian Languages + Top World/UN Languages) via the browser-native Web Speech API (zero app download).
- **Direct Verified Artisan Directory** with official Government Handicraft Pehchan Card IDs, transparent fair pricing, and direct **WhatsApp click-to-chat** (`https://wa.me/...`) links localized in all 33 languages.
- **Interactive Heritage Map & Routing Engine** via free OpenStreetMap & Leaflet.js with GPS user location mapping.
- **Always-Pinned Pending Travel Plans** at the top of the homepage for seamless travel coordination.
- **Memories Panel & Photo Sharing** with privacy controls (Public vs. Private) and a **48-hour Admin Verification SLA**.
- **Community Unlisted Place Submissions** with a **24–36 hour Admin Moderation SLA**.
- **PIN-Protected Admin Governance Dashboard** (`PIN: 1947`).

## 🏛️ 2. Regional Craft Clusters & Heritage Routes Mapped

### 🌾 West Bengal
- **Bishnupur & Bankura (Terracotta & Baluchari Silk):** 17th-century terracotta architecture (Rasmancha, Jor Bangla) and the world-famous Bankura Horse from Panchmura village.
- **Purulia (Chhau Masks):** Charida artisan village crafting vibrant, GI-tagged papier-mâché masks for martial Chhau dance.
- **Pingla & Naya (Patachitra Scroll Painting):** Living museum of Patua folk balladeers singing *Pater Gaan* and preparing organic botanical pigments.
- **Bolpur & Santiniketan (Kantha & Leather/Batik):** Tagore’s rural legacy at Amar Kutir, Nakshi Kantha needlework, and embossed leathercraft.
- **Curated Trails:** *The Rarh Craft & Temple Route*, *The Medinipur Folk Art Route*, *The Murshidabad Silk Route*, *Kolkata Cultural & Artisan Trail*.

### 🏺 Bihar
- **Madhubani (Mithila Region):** Ancient wall and paper painting traditions in Jitwarpur and Ranti (Kachni, Bharni, Godna) using bamboo twigs and natural dyes.
- **Patharkatti (Gaya):** Centuries-old Mauryan stone carving guild chiseling black granite into meditative Buddha sculptures.
- **Curated Trails:** *Bihar Stone Craft & Heritage Trail*, *Mithila Living Art & Heritage Circuit*.

### 🏹 Jharkhand
- **Hazaribagh (Sohrai & Khovar Murals):** UNESCO-recognized and GI-tagged matriarchal wall art celebrating harvest and fertility, etched with combs using natural earth mud.
- **Saraikela-Kharsawan (Dhokra Metal & Royal Chhau):** 4,000-year-old lost-wax (*cire perdue*) bell-metal casting and royal mask guilds.
- **Curated Trail:** *The Grand Tribal Heritage & Craft Circuit*.

## 🏗️ 3. System Design Architecture (Inspired by Hayk Simonyan's Principles)

The application architecture follows key production system design tenets:

```
[ Tourist Mobile Browser ] (Zero App Download, Sub-200KB Initial Load)
          │
          ├── Dual Clocks (IST vs Local Time via Intl.DateTimeFormat)
          ├── Multi-Language State (English, বাংলা, हिन्दी)
          ├── Always-On Pinned Pending Travel Plans Banner
          │
          ├── [ Presentation & Map Layer ]
          │     ├── Leaflet.js + OpenStreetMap (100% Free CDN Tiles)
          │     ├── Custom Themed Pins per State / Craft Discipline
          │     ├── Curated Route Polylines & Distance Calculation
          │     └── GPS User Beacon ("Locate Me" + Haversine Nearest Cluster Finder)
          │
          ├── [ Scan-to-Listen Audio Engine ]
          │     ├── Web Speech API (window.speechSynthesis)
          │     ├── Real-time Audio Waveform & Playback Rate Controls (0.85x - 1.35x)
          │     ├── Simulated On-Site QR Scanner
          │     └── Dynamic Site QR Generator (api.qrserver.com)
          │
          ├── [ High-Resilience Read-Through Storage ]
          │     ├── Client-Side LocalStorage Cache (Offline Village Resilience)
          │     └── RESTful Stateless Node.js API (/api/sites, /api/artisans, /api/plans, /api/memories)
          │
          └── [ Verified Community & Governance Layer ]
                ├── Direct WhatsApp Click-to-Chat (Zero Financial Gateway Risk)
                ├── Memories & Photo Gallery (Public/Private Toggle + 48h SLA)
                ├── Unlisted Craft Place Submissions (24-36h SLA)
                └── PIN-Protected Cultural Custodian Portal (PIN: 1947)
```

1. **Stateless REST & Clean Separation:** The frontend is decoupled from the backend. The Node.js server provides clear REST endpoints (`/api/data`, `/api/sites`, `/api/plans`, `/api/memories`, `/api/places`, `/api/admin/*`).
2. **Offline-First Resilience:** In rural areas with weak cellular reception, the app reads from its in-memory/LocalStorage cache. All interactions remain completely functional.
3. **Zero Financial Intermediary Risk:** Rather than managing sensitive credit card gateways, Sanskriti uses the official WhatsApp Click-to-Chat standard (`https://wa.me/<phone>?text=...`) with pre-filled inquiries, directing 100% of payment to the artisan.
4. **Governance with SLA Timers:** User submissions (photos and unlisted craft clusters) are held in moderation queues with SLA countdown timers (48 hours for photos, 24–36 hours for new places).

## ⚡ 4. How to Run & Deploy

### Quick Start (Local Node.js Server)
The server uses native Node.js with **zero external npm dependencies**:
```bash
# In the project directory:
node server.js
```
Open your browser to: **`http://localhost:3000`**

### Alternative: Run 100% Serverless / Static
You can also open `public/index.html` directly in any web browser or deploy the `public/` directory to **GitHub Pages**, **Vercel**, or **Netlify** with zero backend infrastructure needed!
